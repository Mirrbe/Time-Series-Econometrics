# Time-Series-Econometrics
github.com/Mirrbe/Time-Series-Econometrics is part of my personal portfolio of different statistical and econometric methods applied to financial market analysis. Applied methods will be programmed in Python.

In this repository, we apply time series econometrics to financial markets. 

### Following methods will be used:
- **AutoRegressive Integrated Moving Average (ARIMA)** (done)
- **Generalized Autoregressive Conditional Heteroskecasticity (GARCH)** (in progress)
- **Vector Autoregression (VAR)** (in progress)
- **XGBoost (Gradient Tree Boost)** (in progress)
...
